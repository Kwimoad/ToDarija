# Contribution Guide for ToDarija

Thank you for your interest in contributing to ToDarija!

## How to contribute?
- Fork the repository and create a branch for your changes.
- Submit your improvements via a well-documented Pull Request (PR).
- Add unit tests for any new features.
- Follow the project structure and naming conventions.

## Best Practices
- Document your code and PRs.
- Ensure your code compiles and all tests pass.
- Be respectful in all communications.

For any questions, open an issue or contact the maintainers.
